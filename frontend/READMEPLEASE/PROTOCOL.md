### В этом документе описан протокол общения frontendMM с модулями V1.0

### Общий порядок общения:

* При подключении клиент присыет серверу приведственное сообщение type: H в нём указывается имя модуля, версия протокола, регестрированный тип модуля

* В ответ на приветственное сообщение сервер присылает клиенту аналогичное сообщение или ошибку type: E если что - то пошло нетак

* Если процедура знакомства прошла успешно оба устройства выбирают меньшую версию протокола

* Далее общение идёт в формате оповещение клиента, рассылка всем подписанным

* При надобности отключения одна из сторон отправляет прощальное сообщение type: H, isEnd = true и ожидает ответа

* Вторая сторона отправляет аналогичное сообщение или type: E

* Если обе стороны отправили корректное сообщение о закрытии соединение немедленно закрывается

###### Все общение ведётся в формате json byte array строками

###### Обязательное поле Type:

Поле type отвечает за общий тип сообщения, варианты:

* E - error ошибка модуля или сервера, содержит поля error (данная версия протокола пока не предполагает использование данного поля)

* H - приветственное/прощальное сообщение, содержит в себе поля isEnd, name, dType, protocolVersion

* P - оповещение, содержит поля dType, data - json обьект который будет пересылатся подписчикам

* S - только от сервера, содержит поля sType, data



### Примеры

```json
{
    "STTMicrophoneV1" : {
        "public" : ["detectedText"],
        "sub" : ["Claper.twoClaps"]
    },
    
    "Claper" : {
        "public" : ["twoClaps"],
        "sub" : []
    }
    
    "AI" : {
        "public" : ["textWithVoice", "text"]
        "sub" : ["STTMicrophoneV1.detectedText"]
    }
}
```
