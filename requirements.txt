#
# EyeTrax — внешняя библиотека, лежит в libs/, а libs/ не в Git. На новой
# машине её нужно положить рядом с репозиторием:
#   git clone https://github.com/schuilders/EyeTrax libs/EyeTrax-master
#   .venv\Scripts\python.exe -m pip install --no-deps ./libs/EyeTrax-master
# Остальные зависимости EyeTrax берутся из системного окружения. numpy<2
# недоступен на Python 3.13, но EyeTrax 0.4.0 работает и с numpy 2.x.
#
