### Описание папки

* server.py - основной и единственный файл сервера (необходим server.conf)

* server.conf - конфиг сервера

* client.py - файл/библиотека для работы с сервером (необходим client.conf)

* testCLI.py - навайбкоженный клиент для теста работы сервера, говорилка

### Основные функции client.py

* connect(client) - подключение к серверу из конфига

* send_responce(client, messages, stream) - client (ну тут понятно), messages - массив с историей диалога (подробнее на docs ollama), stream - стоит ли выдавать ответ потоково (полезно например для визуализации)

* set_model (in dev) - включить определённую модель
